# Ivy Homes — SWE Internship Assignment

A real-estate browsing application built for the Ivy Homes SWE internship
assignment.

The application provides authenticated property browsing, filtering,
pagination, listing details, saved listings, rentals, projects, and a data
insights dashboard.
